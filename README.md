Mario-Inspired 2D Platformer

About the Project

This is a 2D platformer developed using the Godot Engine for an assignment in my game programming class. The assignment focuses on core game development concepts, including player movement, level design, enemy interactions, collectibles, camera behavior, and user interface design.

Features

2D platforming gameplay

Player character and level environment

Enemies within the level

Collectible cherries

Score display and tracking

Camera following the player

Game-over interface

Scenes organized using Godot's node and scene system

Technologies Used

Game Engine: Godot Engine 4.6.2

Programming Language: GDScript

Game Type: 2D Platformer

Version Control: Git and GitHub

Project Structure

The repository contains the Godot project configuration, scenes, scripts, and assets required to develop and run the game.

project.godot — Main Godot project configuration

.tscn files — Game scenes

.gd files — Game logic and scripts

Asset folders — Sprites and textures

How to Open and Run the Game

Install Godot Engine.

Clone or download this repository to your computer.

Open Godot and import the project by selecting the project.godot file.

Open the project in the Godot editor.

Press F5 to run the project's main scene.

Controls

For controls, I used W, A, and D. A and D move left and right, and W is for jumping. I also used the left and right arrow keys along with the spacebar.
